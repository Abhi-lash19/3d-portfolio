# Project brief

Build Abhilash Giri's production portfolio around My World: a soft sculpted floating island in sapphire and amber, with an approachable fictional avatar. Communicate backend engineering, AWS, system integration and effective use of AI to deliver useful tools. Support public sharing on LinkedIn and GitHub.

Visitors can immediately read the introduction and scroll through all information. On suitable desktops, a progressively loaded 3D world adds exploration. On phones it is optional via “Step into my world” (proposed button copy). Projects, experience, books and contact remain equally accessible outside the scene.

Primary outcome: a visitor understands Abhilash's skills, sees evidence in selected work and can contact him. Secondary outcome: memorable exploration without waiting for character animations to access content. Exploration loop: choose or walk to a landmark, discover work, open a readable panel, follow a project or return to explore. No game pressure, scores, combat or loss states.

Budget: zero paid assets/services. Use the existing React/Vite/React Three Fiber stack where compatible. Cloudflare Pages Free is the approved host, with a new public address and intended private GitHub source. See ANALYTICS_PLANNING.md. Development stays on portfolio-v2 until release acceptance and an explicit merge decision. Both desktop and mobile are first-class; browser capability determines quality, never browser branding.
